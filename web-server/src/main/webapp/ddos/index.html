HTTP-belastningstest

Brug kun testen mod systemer, du har tilladelse til at belastningsteste.

Klar.

Hver tråd sender et GET-request og venter på hele svaret, før næste request sendes. Browseren begrænser antallet af forbindelser. Andre domæner skal tillade CORS; HTTPS-sider kan ikke sende requests til HTTP. Testen er derfor en simpel belastningstest fra én browser.
