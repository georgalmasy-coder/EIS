# Interface Management Help

The Interface Management matrix shows interfaces between **Functions**.

- Rows represent the **From Function**.
- Columns represent the **To Function**.
- Grey diagonal cells represent the same function and cannot contain an interface.

## Filtering the Matrix

- Select **Show overdue only** to show interfaces where the next IRL meeting date has passed.
- Select one or more **IRL** values to show only interfaces with those values.
- Clear the selected filters to show the complete matrix again.

## Cell Content

An interface cell can show:

- **IRL**
- Selected **Classifications**
- **Next Irl Meeting**

An overdue next IRL meeting is marked in the cell.

## Creating or Editing an Interface

Double-click a matrix cell to open its interface dialog. You can also right-click the cell and select:

- **Create Interface** when the cell does not contain an interface.
- **Edit Interface** when an interface already exists.

The dialog shows information about the From and To Functions. Select an IRL, an optional next IRL meeting date, and zero or more classifications.

Classifications are sorted by code and divided into collapsed groups. Select a group to expand it and display its classifications. The group heading shows the codes currently selected in that group, for example `B_ Signals (B_, BA)`.

Select **Save** to store the interface or **Cancel** to close the dialog without saving.

## Removing an Interface

Right-click a cell containing an interface and select **Remove Interface**. Review the interface information in the confirmation dialog and then select:

- **Remove Interface** to remove it.
- **Cancel** to keep it.

The remove option is unavailable for empty cells.

## Editing a Function

Double-click a row or column header to open the corresponding Function edit page.
