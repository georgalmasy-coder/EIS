# System Requirement

This page is used to work with System Requirements in the selected project.

The page contains three views:

- **List view**
- **Horizontal diagram**
- **Vertical diagram**

You can switch between the views by using the buttons at the top of the page.

## List View

The list view shows System Requirements in a table.

From this view you can:

- search for requirements
- filter active/inactive requirements
- group rows by dragging a column header into the Group by area
- sort by columns
- resize column widths
- open a requirement for editing
- create a new root requirement
- import and export requirements

## Filtering

Use the search field to filter the requirement list.

The search matches values such as:

- Requirement ID
- Name
- Description

If **Active only** is selected, only active requirements are shown.

## Sorting

Click a column header to sort the table.

Click the same column again to switch between ascending and descending sorting.

## Resizing Columns

Columns can be resized by dragging the resize handle in the column header.

Column widths are saved locally in the browser.

## Opening a System Requirement

Double-click a row to open the requirement in the edit page.

You can also use the context menu on the row.

## Creating a Root System Requirement

Use the **Add Root** button to create a new root requirement.

A root requirement is a requirement at the top level of the hierarchy.

## Creating a Sub System Requirement

Sub requirements are created from an existing requirement.

A sub requirement is placed below the selected requirement in the hierarchy.

## Horizontal Diagram

The horizontal diagram view shows the requirement hierarchy from left to right.

The diagram typically contains:

- Project
- Level 1
- Level 2
- Level 3
- Level 4

The connection lines show the parent/child relationship between requirements.

## Vertical Diagram

The vertical diagram view shows the requirement hierarchy from top to bottom.

The connection lines show the parent/child relationship between requirements.

## Download PDF

When you are in a diagram view, you can download the diagram as a PDF.

The PDF page format depends on the diagram type:

- **Horizontal diagram** is exported as A4 portrait
- **Vertical diagram** is exported as A4 landscape

The PDF attempts to show five levels on the same page:

- Project
- Level 1
- Level 2
- Level 3
- Level 4

If the diagram contains many requirements, the PDF is split across multiple pages.

## Import

Import is used to load System Requirements from a file.

After import, the list is reloaded so the new or updated requirements are shown.

## Export

Export is used to export System Requirements.

Depending on the configuration, different formats may be available, for example:

- Excel
- CSV
- PDF
- XML

## Context Menu

Right-click a requirement to open the context menu.

The available actions depend on the selected view and the selected requirement.

Typical actions are:

- Edit requirement
- Create sub requirement
- Create root requirement

## Tips

- Use the list view for searching, filtering and general overview.
- Use the diagram views to understand hierarchy and relationships.
- Use PDF export when the diagram needs to be shared or archived.
