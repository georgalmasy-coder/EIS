# Logical Structure Edit

This page is used to create, edit, or view a logical structure.

The page is organized into tabs containing logical structure information and related data.

## Basis Info

The **Basis Info** tab contains the main fields for the logical structure.

Here you can typically edit:

- ID or code
- name
- description
- priority
- owner
- date
- active/inactive state

Fields marked with `*` are required.

## History

The **History** tab shows historical versions of the logical structure.

You can double-click a historical version to open it.

Historical versions are opened in read-only mode.

## Read-only Mode

When a historical version is opened, the page is read-only.

This means that:

- fields cannot be changed
- Save is disabled
- notes cannot be added
- attachments cannot be added
- relations cannot be added

Use **Cancel** to go back.

## Attachments

The **Attachments** tab shows files attached to the logical structure.

You can:

- add an attachment
- provide a description
- open supported attachments in the browser

A description is required when uploading an attachment.

## Notes

The **Notes** tab shows notes for the logical structure.

You can:

- add a note
- edit existing notes by double-clicking them

## Links

The **Links** tab is reserved for future functionality.

## Linked To ...

The **Linked To ...** tab shows relations to other elements.

You can open a relation by double-clicking the row.

Creating new relations is currently a placeholder.

## Save

Click **Save** to save your changes.

After saving, you return to the overview page.

## Cancel

Click **Cancel** to leave the page without saving.

You return to the page you came from.
