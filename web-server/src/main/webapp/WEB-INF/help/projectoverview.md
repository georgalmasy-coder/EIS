# Project Overview

Project Overview-siden giver et hurtigt og præcist overblik over et specifikt projekts aktuelle tilstand og fremdrift. Siden er designet til at hjælpe dig med at forstå projektets status og identificere de næste vigtige skridt i udviklingsprocessen.

## Oversigtens indhold

### Project Status
Dette panel viser nøgleinformationer om projektet:
- **Status og Prioritet**: Projektets aktuelle fase og vigtighed.
- **Tidslinje**: Start- og slutdato for projektet.
- **Budget**: Oversigt over allokeret budget i både dage og værdi.
- **Project Details**: Klik på denne knap for at redigere de grundlæggende projektinformationer.

### Recommended Steps
Her præsenteres de mest kritiske opgaver, der bør udføres nu for at sikre projektets fremdrift. Det kan f.eks. være tildeling af ejere til strukturer eller færdiggørelse af specifikke modeller.

### Systems Engineering Assets
Dette område giver direkte adgang til projektets kerneelementer i R-F-L-P modellen:
- **Requirements (R)**: Antal og adgang til kravspecifikationer.
- **Functions (F)**: Overblik over den funktionelle arkitektur.
- **Logical Structure (L)**: Den logiske opbygning af systemet.
- **Physical Structure (P)**: Den fysiske realisering og komponentstruktur.

Hvert kort viser det aktuelle antal elementer inden for kategorien, hvilket giver en indikation af modelmodenheden.

## Navigation
Du kan altid gå direkte til det tekniske arbejde ved at klikke på **Continue engineering** øverst til højre, eller dykke ned i de enkelte Systems Engineering områder via deres respektive kort.
