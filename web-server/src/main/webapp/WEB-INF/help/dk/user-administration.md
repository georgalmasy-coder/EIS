# Brugeradministration

Siden viser den aktuelle kundes brugere. Dobbeltklik på en bruger for at åbne redigeringsdialogen.

## Redigeringsdialog

- **Basis** indeholder brugerens hovedfelter.
- **Projects** viser kundens aktive projekter og lader administratoren tildele adgang.
- **Security** indeholder felter og handlinger vedrørende MFA.
- **Password** viser, om en adgangskode er oprettet, og giver adgang til nulstilling.

## Sikkerhed – Security

- **Reset MFA**: Rydder den aktuelle MFA-opsætning og kræver ny opsætning.
- **Disable MFA**: Deaktiverer MFA for brugeren.
- **Mark reset required**: Kræver nulstilling af MFA ved næste login.
- **Clear reset required**: Fjerner kravet om MFA-nulstilling.

## Adgangskode – Password

- **Send reset link**: Sender et link til nulstilling af adgangskoden via mail.
- **Password set**: Skrivebeskyttet indikator for, om der findes en adgangskode.

## Fælles handlinger

- **Save** gemmer ændringerne.
- **Cancel** lukker dialogen uden at gemme.

## Tabelfunktioner

- Søgning filtrerer listen.
- **Group by** grupperer rækker, når du trækker en kolonne til området.
- Kolonnebredder kan tilpasses og gemmes lokalt i browseren.
