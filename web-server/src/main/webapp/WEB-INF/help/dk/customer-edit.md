# Rediger virksomhed

Her kan du se og redigere en virksomhedsprofil.

## Muligheder

- Rediger virksomhedens grundoplysninger.
- Administrer sikkerhedsindstillinger.
- Gennemgå abonnementsoplysninger.
- Administrer betalingsindstillinger.
- Se betalinger.

## Faner

- **Basis Info**: Grundoplysninger.
- **Security**: Sikkerhed.
- **Subscription**: Abonnement.
- **Payment Method**: Betalingsmetode.
- **Payments**: Betalinger.

## Gem

Brug **Save** til at gemme ændringer og **Cancel** til at forlade siden uden at gemme.

## Historiske versioner

Historiske versioner åbnes skrivebeskyttet. Felterne kan ikke ændres, og gemmefunktionen er deaktiveret.
