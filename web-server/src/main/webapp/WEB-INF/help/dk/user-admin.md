# Brugeradministration

BEPA-administratorer bruger denne side til at administrere brugerkonti.

## Brugerliste

Brug listen til at finde og åbne konti.

## Brugerdetaljer

Brug formularen til at vedligeholde kontooplysninger, kontaktoplysninger, roller og adgangsindstillinger.

## Gem ændringer

Gem efter ændringer. Ret eventuelle valideringsfejl, før du gemmer igen.
