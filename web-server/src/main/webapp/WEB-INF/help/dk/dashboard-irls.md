# IRL-dashboard

Siden viser den fysiske arkitektur med TRL, antal dage til næste TRL, antal grænseflader og én kolonne pr. IRL.

## Filtre

Brug TRL-filterlisten og filtrene for overskredne frister til at begrænse de viste rækker.

- Vælg en eller flere TRL-værdier for at vise tilsvarende strukturer.
- Vælg `(blank)` for at medtage strukturer uden TRL-værdi.
- Brug fristfiltrene til kun at vise strukturer med eller uden overskredne frister.

## Redigering

Dobbeltklik på en række for at åbne redigeringssiden for den valgte fysiske arkitektur.

## PDF

Brug PDF-knappen til at hente den aktuelle visning som `dashboard-irls-<projectName>.pdf`.

N2-knappen ved siden af PDF åbner grænsefladestyring for fysisk arkitektur. Den er tilgængelig, når siden er med i din menu.
