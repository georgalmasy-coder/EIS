# Abonnementsredigering

Her administrerer du abonnementsplaner og faktureringsperioder.

## Muligheder

- Søg efter abonnementer.
- Opret et abonnement ud fra et modul.
- Rediger abonnementsoplysninger.
- Administrer faktureringsperioder.
- Gennemgå kunder på det valgte abonnement.

## Liste

Tabellen viser de tilgængelige abonnementsplaner.

## Redigering

Brug dialogen til at ændre datoer, beskrivelser, faktureringsperioder og aktiv status.
