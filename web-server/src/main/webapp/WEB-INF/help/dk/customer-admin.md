# Kundeadministration

BEPA-administratorer bruger denne side til at administrere kundeposter.

## Kundeliste

Brug listen til at gennemgå og søge efter kunder og åbne deres detaljer.

## Kundedetaljer

Brug formularen til at vedligeholde virksomhedsoplysninger, kontaktoplysninger og administrative indstillinger.

## Gem ændringer

Gem siden efter ændringer. Ret eventuelle valideringsfejl, før du gemmer igen.
