# Rediger bruger

- Brug **Basis** til brugerens hovedfelter.
- Brug **Projects** til at give eller fjerne adgang til den aktuelle kundes aktive projekter.
- Brug **Security** til at gennemgå MFA-status og låseoplysninger.
- Brug **Password** til at se, om der allerede findes en adgangskode.
- Efter vellykket lagring vender du tilbage til listen.
