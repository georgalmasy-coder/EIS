# Rediger systemkrav

Her kan du oprette, redigere og se detaljerne for et systemkrav.

Siden har fanerne **Basis Info**, **History**, **Attachments**, **Notes**, **Links** og **Relations**.

## Grundoplysninger – Basis Info

Fanen viser kravets hovedfelter. De kan eksempelvis omfatte krav-ID, navn, beskrivelse, kravstatus, verifikationsstatus, forretningsprioritet, ejer og aktiv status.

Hvilke felter du kan ændre, afhænger af, om siden er åbnet til redigering eller skrivebeskyttet.

## Redigeringstilstand

Når du åbner siden normalt fra systemkravlisten, kan kravet redigeres. Ret felterne, og klik på **Save** for at gemme. **Cancel** vender tilbage til systemkravlisten.

## Skrivebeskyttet tilstand

Når du åbner en historisk version fra **History**, er siden skrivebeskyttet. Du kan se en tidligere version, men ikke ændre eller gemme data.

Følgende handlinger er deaktiveret:

- Gem ændringer.
- Rediger felter.
- Tilføj noter.
- Tilføj vedhæftninger.
- Tilføj relationer.
- Slet vedhæftninger.

Øverst på siden vises oplysninger om den historiske version.
