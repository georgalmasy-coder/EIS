# Brugeradministration

Siden viser de brugere, som er knyttet til den aktuelle kunde.

Kolonnerne viser navn, rolle, mailadresse, telefon, afdeling, seneste login og aktiv status.

Tabellen understøtter søgning og tilpasning af kolonnebredder. Bredderne gemmes lokalt i browseren for den aktuelle browserprofil.
