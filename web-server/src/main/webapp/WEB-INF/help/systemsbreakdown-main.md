# Physical Structure

This page is used to view, filter, import, export, and maintain Physical Structure.

## Views

The page has three views:

- **List view** shows physical structure as a table.
- **Horizontal diagram** shows the hierarchy from left to right.
- **Vertical diagram** shows the hierarchy from top to bottom.

The selected view is saved automatically, so the page opens with the same view the next time.

## Search and filter

Use the search field to filter by ID, name, description, or status.

The filter is applied to:

- the list view
- the horizontal diagram view
- the vertical diagram view

Select **Active** to show only active systems.

Use **Clear filter** to reset the search and active filter.

## List view

In the list view, you can:

- sort by clicking a column header
- group rows by dragging a column header into the Group by area
- resize columns by dragging the right edge of a column header
- open a system by double-clicking the row
- open the context menu by right-clicking a row

Sorting and column widths are saved automatically.

## Diagram views

The diagram views show physical structure as a hierarchy with the project as the root node.

In the diagram views, you can:

- double-click a system to open the edit page
- right-click a system to create a child system
- right-click the project node to create a root system
- download the diagram as PDF

The PDF button is only shown in the diagram views.

## Import and export

Import and export are available in list view.

When importing, select a supported file.

When exporting, select the format and whether inactive systems should be included.

## Create and edit

Use the plus button to create a new root system.

Use the context menu to:

- edit a system
- create a child system
- create a new root system

The edit page opens in the correct mode depending on the selected action.
