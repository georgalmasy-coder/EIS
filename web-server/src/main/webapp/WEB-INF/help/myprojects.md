# All Projects

This page gives you a quick overview of all the projects you are associated with. From here, you can easily navigate to the project you want to work on.

## Features on the Page

### Project Overview
All your projects are presented as cards in a grid. Each card shows:
- **Project Name**: The name of the project.
- **Status**: The project's current phase (e.g., Active, On Hold).

### Search and Filtering
In the top bar, you will find a search field where you can filter your projects. 
- You can search by name, number, and customer.
- The list updates instantly as you type.

### Project Selection
To open a project, simply click on the project card. This will take you to the **Project Overview** for the selected project, where you can see more detailed status and continue technical work.

## Tips
- If you have many projects, the search function is the fastest way to find the right project.
- You can always return to this list via the main menu under "All Projects".
