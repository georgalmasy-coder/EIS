# Stakeholder Requirement

This page is used to get an overview of the project’s stakeholder requirements.

You can work with stakeholder requirements in three views:

- List view
- Horizontal diagram view
- Vertical diagram view

## List View

The list view displays stakeholder requirements in a table.

You can:

- sort by columns
- group rows by dragging a column header into the Group by area
- resize column widths
- search by ID, name, and description
- filter active requirements
- open a requirement by double-clicking the row

## Search

Use the search field to filter both the list and the diagrams.

The search includes:

- ID
- name
- description

Click **Clear filter** to reset the search.

## Active Filter

The **Active** filter is enabled by default.

When enabled, only active stakeholder requirements are shown.

Disable the filter to include inactive stakeholder requirements.

## Diagram View

You can switch between:

- horizontal diagram
- vertical diagram

The diagrams show stakeholder requirements hierarchically.

Each box shows:

- ID
- name
- description

Stakeholder requirements do not show status in the diagram boxes.

## PDF Download

When you are in a diagram view, you can download the diagram as a PDF.

The PDF shows the stakeholder requirement diagram for the current view and the current filters.

## Create Stakeholder Requirement

Use the plus button to create a new root stakeholder requirement.

You can also create a sub stakeholder requirement from the context menu on an existing requirement.

## Context Menu

Right-click a stakeholder requirement to open the context menu.

From the context menu, you can:

- edit the stakeholder requirement
- create a sub stakeholder requirement

Right-click the project node in the diagram to create a root stakeholder requirement.

## Import and Export

Import is used to load stakeholder requirements from a file.

Export is used to export stakeholder requirements to a file.

During export, you can choose the format and whether inactive requirements should be included.
