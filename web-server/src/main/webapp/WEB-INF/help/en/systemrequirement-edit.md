# Edit Systems Requirement

This page is used to create, edit and view details for a Systems Requirement.

The page contains several tabs:

- **Basis Info**
- **History**
- **Attachments**
- **Notes**
- **Links**
- **Relations**

## Basis Info

The **Basis Info** tab shows the main fields for the requirement.

Typical fields can include:

- Requirement ID
- Name
- Description
- Requirement Status
- Verification Status
- Business Priority
- Owner
- Active

Which fields can be changed depends on whether the page is opened in edit mode or read-only mode.

## Edit Mode

When the page is opened normally from the Systems Requirement list, the requirement can be edited.

You can change fields and click **Save** to save the changes.

Click **Cancel** to return to the Systems Requirement list.

## Read-Only Mode

When a historical version is opened from the **History** tab, the page opens in read-only mode.

In read-only mode, you can view an earlier version of the requirement, but you cannot change or save data.

In read-only mode the following actions are disabled:

- Save
- editing fields
- adding notes
- adding attachments
- adding relations
- deleting attachments
