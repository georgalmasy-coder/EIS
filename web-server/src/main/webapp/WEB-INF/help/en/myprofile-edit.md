# My Profile

This page is used to maintain your own user account information.

## Profile details

Use the form to review and update your personal information, contact details, and login-related settings.

## Phone number

Select the relevant country code and enter the local phone number. The page validates the phone number format where rules are available.

## Saving changes

Save the page when your changes are complete. If validation errors are shown, correct the highlighted fields and save again.
