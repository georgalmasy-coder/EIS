# Requirements

This page provides a comprehensive overview of the project's **Stakeholder Requirements** and **System Requirements**.

You can switch between the two types of requirements using the tabs at the top of the page. Each tab shows the total number of requirements of that type.

## Navigation and Views

Both Stakeholder and System requirements can be displayed in three different ways:

- **List view**: Displays requirements in a table format with support for sorting, filtering, and grouping.
- **Horizontal diagram**: Displays the hierarchy from left to right.
- **Vertical diagram**: Displays the hierarchy from top to bottom.

Use the view buttons in the header to switch between these formats. Your choice of view is saved independently for Stakeholder and System requirements respectively.

## Stakeholder Requirements

Stakeholder requirements define what the stakeholders expect from the system.

- **Search**: Use the filter to search in ID, name, or description.
- **Grouping**: Drag column headers to the "Group by" zone to organize the list.
- **Diagrams**: The boxes in the diagrams show ID, name, and description.

## System Requirements

System requirements define the technical specifications for the system.

- **Hierarchy**: The diagrams show the relationship from the project and down through different levels.
- **PDF Export**: In diagram view, you can export the hierarchy as a PDF.

## Common Features

### Search and Filtering
The search field in the toolbar filters the current list or diagram. Each tab has its own independent filter settings. The **Active** checkbox allows you to toggle between showing only active requirements or including inactive ones.

### Context Menu
Right-click on a requirement in the list or diagram to:
- **Edit**: Open the requirement for editing.
- **Create sub-requirement**: Add a new requirement under the selected one.
- **Create root requirement**: Add a new requirement at the top level.

### Import and Export
Use the import and export buttons to exchange requirement data with external files (XML, XLSX, CSV, or PDF).
