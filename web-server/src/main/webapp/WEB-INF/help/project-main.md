# Projects

This page shows the project list for the selected customer.

## What you can do

- search in project fields
- clear the current filter
- sort by clicking a column header
- resize column widths by dragging the header edge
- open a project by double-clicking a row
- create a new project with the plus button
- open this help page with the help button

## Search

Use the search field to filter the list.

The search covers the visible project fields in the table.

Use **Clear filter** to reset the search text.

## Sorting

Click a column header to sort the list.

Click the same header again to reverse the sort direction.

## Column widths

Drag the right edge of a column header to change the width.

Column widths are stored in local storage and are restored the next time you open the page.

## Opening a project

Double-click a project row to open the project edit page.

## Creating a project

Use the plus button to create a new project.

The new project opens in the project edit page.

## Help button

The help button opens this help page.
