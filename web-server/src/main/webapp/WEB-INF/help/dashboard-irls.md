# Dashboard IRL

This page shows physical structures with their TRL, days to next TRL, interface counts, and one column per IRL.

## Filters

Use the TRL filter list and the overdue toggles to reduce the visible rows.

- Select one or more TRL values to show matching structures.
- Select `(blank)` to include structures without a TRL value.
- Use the overdue toggles to show only overdue or only not overdue structures.

## Editing

Double-click a row to open the edit page for the selected physical structure.

## PDF

Use the PDF button to download the current view as `dashboard-irls-<projectName>.pdf`.
