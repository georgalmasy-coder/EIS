# Baselines

The Baselines page shows all baselines created for the selected customer and project.

A baseline is an immutable snapshot used to compare changes in requirements and systems breakdown data over time.

## Baseline list

The list contains the following columns:

- **Tag Name**: The name of the baseline.
- **Description**: A short description of the purpose of the baseline.
- **Created By**: The user who created the baseline.
- **Created At**: The date and time when the baseline was created.

## Create a new baseline

Use the **plus** icon button to create a new baseline.

When creating a baseline, you must enter:

- **Tag Name**
- **Baseline description**

The tag name must be unique for the selected customer and project.

## Open baseline detail

Double-click a baseline row to open the baseline detail page.

The detail page shows:

- Baseline metadata
- Changes in stakeholder requirements
- Changes in system requirements
- Changes in systems breakdown

## Sorting

Click a column header to sort the baseline list by that column.

Click the same column again to switch between ascending and descending sorting.
