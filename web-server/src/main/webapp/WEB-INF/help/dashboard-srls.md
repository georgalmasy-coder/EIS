# Dashboard SRL

Project PRL marks the lowest, current and highest calculated SRL levels on the active SRL scale. Current Level is the arithmetic mean of the individual SRL levels rounded to the nearest whole level. The markers align with the SRL headings below; their numeric values are not displayed.

The system list is sorted naturally by SBS code and grouped under level 1 systems. All groups start collapsed. Each section bar shows the level 1 code, name, number of underlying systems and their rounded average SRL as a line ending in a small red marker. Select the bar to expand or collapse the underlying systems. Level 1 is shown only in the section bar. A system without children uses its own calculated level.

Each red marker in an expanded group indicates the system's calculated SRL level. Hover over its line to see the corresponding code from the SRL lookup. Group and Project PRL markers use the same lookup codes in their tooltips.

SBS codes are indented by hierarchy level; system names align in the same column. Double-click a system or its group header to open Edit Physical Architecture. Saving reloads the dashboard and recalculates its values.

Systems without a calculated level display “Not calculated” and are excluded from summaries. Reload the page to reload the calculations for the current project.

Use the PDF button at the top right to download the complete dashboard, including all systems in collapsed groups. Level 1 codes and names are bold; other levels are indented. The PDF includes Project PRL, subsystem counts, SRL markers and page numbers.

The N2 button beside PDF opens Interface Management for Physical Architecture. It is available when that page is included in your menu.

Drag the right edge of SBS Code, System Name or # Subsystems to resize the column. Widths are saved in your user preferences. System names stay on one line; hover to see a truncated name in full. Focus a column divider and use the arrow keys to adjust its width.
