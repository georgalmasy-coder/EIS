# Project Edit

This page is used to view, create, and edit a project.

## What you can do

- edit the project basis information
- add and manage notes
- add and manage attachments
- save changes
- cancel and return to the previous page

## Page structure

The page is split into these tabs:

- **Basis Info**
- **Notes**
- **Attachments**

## Basis Info

The **Basis Info** tab contains the main project fields.

Typical fields include:

- project name
- owner
- category
- priority
- status
- start date
- end date
- budget fields
- department

Some fields may be read-only depending on the current mode or the selected project version.

## Project status

The project status field shows the current state of the project.

In create mode the status is initialized by the system.

In edit mode you can typically change the status if the current project state allows it.

## Notes

The **Notes** tab shows project notes.

Use **Add Note** to create a new note.

Notes are useful for:

- comments
- clarification
- review input
- internal observations

## Attachments

The **Attachments** tab shows files attached to the project.

Use **Add Attachment** to upload a file and add a description.

Attachments can be used for:

- drawings
- specifications
- meeting notes
- screenshots
- external documents

## Saving

Use **Save** to store your changes.

Use **Cancel** to leave the page without saving.

## Historical versions

If a historical version is opened, the page is read-only.

In that mode, saving and editing actions are disabled.
