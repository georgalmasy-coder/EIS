# Customer and project settings

Select **Customer → Security** or **Project → Traceability matching** in the navigation.
Only the current customer and selected project are editable. Select another project from the main menu to edit its settings.

Hover over a setting for an explanation. Search finds settings across both categories.
Missing values display their defaults. An empty stopword list disables stopword filtering.

**Restore defaults** resets the selected category in the editor. **Save** persists changes in both categories.
