# Interface Management Help

The Interface Management matrix shows relationships between **Physical Structures** on both axes.

Rows represent the source physical structure.  
Columns represent the target physical structure.

Each cell indicates the interface data stored for the selected source and target pair.

The matrix can be filtered with:

- **Show overdue only** to display only rows and columns that are involved in at least one overdue interface
- **IRL** checkboxes to limit the matrix to selected IRL values

---

## Cell Content

Cells with data show:

- IRL
- Classification
- Next Irl Meeting
- Changed By
- Changed

Cells where source and target are the same physical structure are shown with a grey background and remain empty.

---

## Editing

Double-click a row or column header to open the physical structure edit page.

Double-click a matrix cell to open the interface dialog for that pair.
