# Logical Structure

This page is used to get an overview of the project’s logical structures.

You can work with logical structures in three views:

- List view
- Horizontal diagram view
- Vertical diagram view

## List View

The list view displays logical structures in a table.

You can:

- sort by columns
- group rows by dragging a column header into the Group by area
- resize column widths
- search by ID, name, and description
- filter active logical structures
- open a logical structure by double-clicking the row

## Search

Use the search field to filter both the list and the diagrams.

The search includes:

- ID
- name
- description

Click **Clear filter** to reset the search.

## Active Filter

The **Active** filter is enabled by default.

When enabled, only active logical structures are shown.

Disable the filter to include inactive logical structures.

## Diagram View

You can switch between:

- horizontal diagram
- vertical diagram

The diagrams show logical structures hierarchically.

Each box shows:

- ID
- name
- description

Logical structures do not show status in the diagram boxes.

## PDF Download

When you are in a diagram view, you can download the diagram as a PDF.

The PDF shows the logical structure diagram for the current view and the current filters.

## Create Logical Structure

Use the plus button to create a new root logical structure.

You can also create a sub logical structure from the context menu on an existing logical structure.

## Context Menu

Right-click a logical structure to open the context menu.

From the context menu, you can:

- edit the logical structure
- create a sub logical structure

Right-click the project node in the diagram to create a root logical structure.

## Import and Export

Import is used to load logical structures from a file.

Export is used to export logical structures to a file.

During export, you can choose the format and whether inactive logical structures should be included.
