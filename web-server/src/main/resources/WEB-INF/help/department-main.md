# Department Administration

## List
- The list shows departments for the current customer only.
- Double-click a row to open it in the edit dialog.
- The list is sorted by department name.
- Use the add button to create a new department.

## Edit dialog
- `Department name` is required and can contain up to 10 characters.
- `Department description` is optional and can contain up to 255 characters.
- `Active` controls whether the department is available in the system.
- Save stores the department for the current customer and refreshes the list.
