# Baseline detail

The Baseline detail page shows information about the selected baseline and the changes recorded since the previous baseline.

## Baseline information

The top section displays metadata for the selected baseline:

- **Tag Name**: The name of the baseline.
- **Created By**: The user who created the baseline.
- **Created At**: The date and time when the baseline was created.
- **Previous Baseline**: The date and time of the previous baseline.
- **Description**: A description of the purpose of the baseline.

## Change lists

The page contains three change lists:

1. **Stakeholder requirements**
2. **System requirements**
3. **Systems breakdown**

Each list can be expanded or collapsed.

The columns show:

- **Activity**: Whether the item was created, modified, or inactivated.
- **Id**: The item code.
- **Name**: The item name.
- **Last modified by**: The user who last modified the item.
- **Last modified**: The date and time of the latest change.

## Open a changed item

Double-click a row in one of the change lists to open the item on its edit page.

When returning from the edit page, you are taken back to the Baseline detail page.

## PDF

The **PDF** icon button generates a PDF report containing:

- Baseline information
- Stakeholder requirement changes
- System requirement changes
- Systems breakdown changes

The PDF includes all rows from the three change lists.

## Back to baselines

The **back arrow** icon button returns to the baseline overview.
