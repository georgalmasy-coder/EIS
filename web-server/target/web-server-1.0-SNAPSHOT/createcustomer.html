1. Select module

Select the module that should be enabled for the new customer.

Basis Module Requirements

Basis Module is to support the complete lifecycle of requirements: from capturing stakeholder needs, deriving system-level specifications, establishing traceability, to verifying compliance.

This software should help product managers, engineers, QA, and business stakeholders collaborate efficiently and ensure full requirement coverage, traceability, and testability.

Price XXXX kr/monthly

Pro Module Requirements

Pro Module is to support and integrate the complete lifecycle of full RFLP methodologies: (R) from capturing stakeholder and system requirements, establishing traceability between stakeholder and system requirement, including all functions in Basis Module.

Price YYYYY kr/monthly

Master Module

Master Module includes all functionality from Pro Module plus TRL, IRL, DRL and Configuration / Modularisation architectures.

This module is intended for organisations that need extended architecture management, maturity tracking and advanced configuration support across complex product platforms.

Price ZZZZZ kr/monthly
